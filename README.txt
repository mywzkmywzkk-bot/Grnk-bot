# Fadi Music PHP Bot

الملفات:
- bot.php
- config.php
- cookies.txt
- Procfile

الخطوات:
1. افتح config.php وحط توكن البوت الجديد مكان PUT_YOUR_BOT_TOKEN_HERE.
2. افتح cookies.txt والصق كوكيز يوتيوب بصيغة Netscape.
3. ارفع الملفات على Railway.
4. شغل Redeploy.

ملاحظة مهمة:

style = primary
